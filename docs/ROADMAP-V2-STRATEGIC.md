## Point 2 détaillé — Landing page international

**Sections obligatoires** : hero headline → subheadline → CTA (primary + secondary) → trust badges → 3 value pillars → 3 personas → proof of quality → pricing → FAQ → CTA final.

**Règles copy** :
- ❌ Pas de jargon tech, pas de "we built"
- ✅ Bénéfice utilisateur, pas fonctionnalité
- ✅ Parler apprentissage clinique, pas app
- ✅ Démontrer la qualité éditoriale

**Exemples de headline** :
- "Clinical reasoning for the next generation of medical learners"
- "Learn with evidence-based clinical pathways, structured cases, and exam-focused progression"

## Point 3 détaillé — Trust framework médical

**À rendre visible dans chaque fiche** :
- Source (HAS, OMS, collèges, sociétés savantes)
- Date de mise à jour
- Reviewer / institution
- Statut (draft / reviewed / published / deprecated)
- Niveau d'evidence
- Disclaimer médical
- "What this is / what this is not"

**Pages publiques obligatoires** :
- Editorial policy
- Clinical validation
- Methodology
- Review process
- Sources & references
- Changelog public
- Editorial board

**Phrase de positionnement** : "Educational tool, not a diagnostic tool."
