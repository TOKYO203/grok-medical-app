# GARDE-FOUS LÉGAUX — Optimus (App éducative)

> Statut : OBLIGATOIRE. Toute violation bloque la publication.
> Nature : plateforme de révision pour étudiants en médecine.
> AUCUN stockage de données patients, AUCUN diagnostic, AUCUNE prescription.

## 0. Nature du produit (rappel)

Optimus EST : une plateforme de révision médicale pour étudiants.
Optimus N'EST PAS : un dispositif médical, un carnet de santé, un outil de téléconsultation.

## 1. DISCLAIMER (obligatoire, visible)

"Contenu éducatif uniquement, pour étudiants en médecine. Ne remplace pas
un avis médical professionnel. N'utilisez pas ce contenu pour traiter un
patient réel sans validation d'un médecin."

A afficher : sous chaque fiche + dans les CGU + sur la page d'accueil.

## 2. DONNÉES UTILISATEURS (léger)

Seules données collectées :
- email (auth)
- progression (deck_id, cartes vues, scores, streak)
- logs techniques (IP, user-agent) pour sécurité

AUCUNE donnée de santé, AUCUN patient, AUCUN diagnostic utilisateur.

Conservation : tant que le compte existe. Droit à l'effacement depuis /profil.
Loi applicable : Loi malgache 2014-038 (moindre risque car pas de données sensibles).

## 3. PROPRIÉTÉ INTELLECTUELLE (contenu)

- Images : uniquement CC0, CC BY, domaine public (voir IMAGING-SOURCES-POLICY.md)
- Fiches : sources OMS/HAS/SPILF obligatoires, dates de mise à jour
- Interdit : reproduire des extraits de manuels (Elsevier, MedG, UWorld)
- Procédure de retrait (DMCA) en cas de réclamation : 72h

## 4. CONSOMMATEUR (paiements)

- Prix affichés TTC, en Ariary et EUR
- CGU + CGV + droit de rétractation 14 jours (international)
- Aucun prélèvement automatique (achat unique de 3 mois)
- Facture accessible dans /profil

## 5. CONTENU MÉDICAL (déjà couvert)

Voir MEDICAL-AUDIT-PROTOCOL.md. Aucune fiche publiée sans :
- audit IA
- sources vérifiées
- relecture humaine (reviewedBy + reviewedAt)
- disclaimer médical

## 6. AGE

Accès 18+ (ou 16+ avec autorisation parentale pour l'achat).
Mention dans les CGU.

## 7. Ce qui N'EST PAS nécessaire

- Pas d'autorisation CMIL (pas de données de santé patients)
- Pas de marquage CE (pas un dispositif médical)
- Pas d'agrément ARS (pas un service de soin)
- Pas de RGPD renforcé (données basiques seulement)
